## FalkorDB specifics we hit

- `shortestPath()` must be used in `WITH` or `RETURN`, not in `MATCH`, and it is directed only. For undirected checks the Verifier uses `allShortestPaths()` in `MATCH`, which accepts undirected patterns.
- `algo.betweenness` follows edge direction. People only point at repos (`CONTRIBUTES_TO`), so no shortest path ran through a person and every score was 0. A derived reverse edge (`HAS_CONTRIBUTOR`) fixes it.
- `db.idx.vector.queryNodes` yields a cosine **distance** as `score` (lower is closer). Queries convert it to similarity with `1 - score`.
- Relationship aliases are referenced whenever we count, following the known-limitations note that unreferenced relationships are only checked for existence.

## Derived edges (run after every load and by the daily sync)

### KNOWS (authored)

```cypher
MATCH (p:Person)-[:AUTHORED]->(pr:PullRequest)-[:TOUCHED]->(:File)-[:IN_DIR*1..6]->(d:Directory)
WHERE p.isBot = false AND pr.mergedAt IS NOT NULL
WITH p, d, count(DISTINCT pr) AS authored, max(pr.mergedAt) AS last
MERGE (p)-[k:KNOWS]->(d)
SET k.authored = authored, k.authoredLastAt = last
```

### KNOWS (reviewed)

```cypher
MATCH (p:Person)-[rv:REVIEWED]->(pr:PullRequest)-[:TOUCHED]->(:File)-[:IN_DIR*1..6]->(d:Directory)
WHERE p.isBot = false
WITH p, d, count(DISTINCT pr) AS reviewed, max(rv.at) AS last
MERGE (p)-[k:KNOWS]->(d)
SET k.reviewed = reviewed, k.reviewedLastAt = last
```

### KNOWS (lastAt)

```cypher
MATCH (:Person)-[k:KNOWS]->(:Directory)
SET k.authored = coalesce(k.authored, 0), k.reviewed = coalesce(k.reviewed, 0),
    k.lastAt = CASE WHEN coalesce(k.authoredLastAt, 0) >= coalesce(k.reviewedLastAt, 0) THEN k.authoredLastAt ELSE k.reviewedLastAt END
```

### REVIEWS_FOR

```cypher
MATCH (r:Person)-[rv:REVIEWED]->(pr:PullRequest)<-[:AUTHORED]-(a:Person)
WHERE r.isBot = false AND a.isBot = false AND id(r) <> id(a)
WITH r, a, count(rv) AS n
MERGE (r)-[e:REVIEWS_FOR]->(a)
SET e.count = n
```

### CONTRIBUTES_TO (authored)

```cypher
MATCH (p:Person)-[:AUTHORED]->(t:Thread)-[:IN_REPO]->(r:Repo)
WHERE p.isBot = false
WITH p, r, sum(CASE WHEN t:PullRequest THEN 1 ELSE 0 END) AS prs, sum(CASE WHEN t:Issue THEN 1 ELSE 0 END) AS issues
MERGE (p)-[c:CONTRIBUTES_TO]->(r)
SET c.prs = prs, c.issues = issues
```

### CONTRIBUTES_TO (reviews)

```cypher
MATCH (p:Person)-[rv:REVIEWED]->(:PullRequest)-[:IN_REPO]->(r:Repo)
WHERE p.isBot = false
WITH p, r, count(rv) AS n
MERGE (p)-[c:CONTRIBUTES_TO]->(r)
SET c.reviews = n, c.prs = coalesce(c.prs, 0), c.issues = coalesce(c.issues, 0)
```

### HAS_CONTRIBUTOR

```cypher
MATCH (p:Person)-[c:CONTRIBUTES_TO]->(r:Repo)
WHERE coalesce(c.prs, 0) + coalesce(c.reviews, 0) >= 3
MERGE (r)-[h:HAS_CONTRIBUTOR]->(p)
SET h.weight = coalesce(c.prs, 0) + coalesce(c.reviews, 0)
```

### CO_CHANGES

```cypher
MATCH (pr:PullRequest)-[:TOUCHED]->(:File)-[:IN_DIR]->(d:Directory)
WITH pr, collect(DISTINCT d) AS ds
WHERE size(ds) > 1 AND size(ds) <= 25
UNWIND ds AS d1
UNWIND ds AS d2
WITH d1, d2, pr WHERE id(d1) < id(d2)
WITH d1, d2, count(DISTINCT pr) AS n WHERE n >= 3
MERGE (d1)-[c:CO_CHANGES]->(d2)
SET c.count = n
```

## Memory, coordination and traces (`tl_mem_<visitor>` and `tl_shared` graphs)

### `writeTurn`

Q13: episodic memory. One Turn per question, chained with NEXT, with its tool calls and the brain nodes they touched.

```cypher
MERGE (s:Session {id: $sid})
ON CREATE SET s.startedAt = $now
CREATE (t:Turn {id: $tid, question: $q, answer: $a, at: $now, verified: $verified, total: $total, mode: $mode, traceId: $traceId})
MERGE (s)-[:HAS_TURN]->(t)
WITH s, t
OPTIONAL MATCH (s)-[:HAS_TURN]->(prev:Turn) WHERE prev.id <> t.id
WITH t, prev ORDER BY prev.at DESC LIMIT 1
FOREACH (_ IN CASE WHEN prev IS NULL THEN [] ELSE [1] END | MERGE (prev)-[:NEXT]->(t))
WITH t
UNWIND $calls AS c
CREATE (tc:ToolCall {tool: c.tool, step: c.step, ms: c.ms, rows: c.rows, cypher: c.cypher})
MERGE (t)-[:RAN]->(tc)
FOREACH (k IN c.refs | MERGE (r:Ref {key: k}) MERGE (tc)-[:TOUCHED_REF]->(r))
```

### `writeFact`

Q15: semantic memory. A fact learned from a turn, optionally about brain nodes.


### `writeCoordination`
