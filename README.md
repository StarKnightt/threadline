# Threadline

A company brain that shows its work. Threadline loads the public GitHub history of an open-source organisation (FalkorDB's own repositories) into a FalkorDB graph of people, pull requests, issues, files, releases and docs. An agent answers questions such as "who should review a change to the vector index code?" by walking that graph, and every hop is shown with the exact Cypher it ran.

Built for WeMakeDevs Graph Hacks (FalkorDB), 15 to 18 October 2026. Work in progress; the full README (setup, graph data model, Cypher catalogue, evaluation) lands during the event.
